Linha verde, back-end

ESG API

API REST para empresas registrarem emissões de CO₂, lançarem compensações e acompanharem indicadores de sustentabilidade.

  • Autenticação JWT com Spring Security e perfis de acesso: USER consulta, ADMIN altera.
  • Esquema Oracle versionado com migrations Flyway e regra de negócio que impede compensar mais CO₂ do que foi emitido.
  • Erros padronizados (400 a 422), Swagger, collection Postman e testes unitários com JUnit.
  • Sobe API e banco com um único docker compose up.
  • Java 17
  • Spring Boot 3
  • Spring Security
  • Spring Data JPA
  • Oracle

  • Docker
  • Swagger
  • JUnit

Linha azul, mobile

SignFlow

App Android para preparar, enviar e assinar documentos PDF pelo celular. Feito individualmente para o Challenge FIAP com a LetsSign.

  • Arquitetura MVVM com repositórios por interface, pronta para trocar o banco local por uma API na próxima sprint.
  • Editor de campos de assinatura sobre o PDF: arrastar, redimensionar e salvar a posição relativa à página.
  • PDF final carimbado com PDFBox, hash SHA-256 do original e trilha de eventos.
  • Senhas com PBKDF2 e reenvio sem duplicar solicitações.
  • Kotlin
  • Jetpack Compose
  • Room
  • Coroutines e Flow
  • PDFBox
  • MVVM
  • JUnit

AlertaPerto

Alertas de alagamento e calor extremo para a rua de cada pessoa, com o que fazer e para onde ir. Global Solution FIAP, desafio CitizenTech.

Linha vermelha, dados

Automação ESG em PL/SQL

Banco Oracle que monitora o consumo de energia de equipamentos IoT e gera alertas de desperdício sozinho.

  • Modelagem de setores, equipamentos, leituras e alertas com chaves estrangeiras e sequence.
  • Quatro triggers: pico de consumo, risco à meta mensal do setor, falha de equipamento e auditoria de mudanças nas metas.
  • Oracle
  • PL/SQL
  • SQL
  • Modelagem de dados
Ver código no GitHub 
CREATE OR REPLACE TRIGGER TRG_ALERTA_PICO_CONSUMO
AFTER INSERT ON LEITURA_CONSUMO
FOR EACH ROW
BEGIN
  -- mais de 50 kWh numa leitura: alerta crítico
  IF :NEW.KWH_REGISTRADO > 50 THEN
    INSERT INTO ALERTA_DESPERDICIO (...)
    VALUES (SEQ_ALERTA.NEXTVAL, :NEW.ID_EQUIPAMENTO,
            SYSDATE, 'Pico de consumo detectado',
            'CRITICO');
  END IF;
END;
