# Portfólio — Christian Santos

Site pessoal publicado em **https://christiangit2025-sys.github.io** com os projetos de back-end, mobile e dados que desenvolvi na FIAP.

- HTML e CSS puros, sem build: abre direto no navegador
- Responsivo, com foco visível no teclado e respeito a `prefers-reduced-motion`
- Cada projeto tem uma cor, inspirada nas linhas do metrô de São Paulo

Para rodar localmente, basta abrir `index.html`.
